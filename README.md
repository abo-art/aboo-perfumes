# ✦ Aboo Perfumes — ИИ-модуль «Парфюмерный Сомелье»

Интеллектуальный веб-сервис на **FastAPI + LLM** с валидацией по ольфакторной базе данных, разработанный по ТЗ. Сервис принимает от пользователя название его прошлого любимого парфюма, проводит короткое диалоговое интервью (**ровно 3 точечных вопроса**) и выдает строго валидированный, ранжированный **ТОП-10 реальных ароматов** с экспертным обоснованием.

---

## 1. Возможности и соответствие ТЗ

| Требование ТЗ | Реализация в проекте |
|---|---|
| **Бэкенд** | Python 3.13, **FastAPI**, Pydantic v2, Pydantic-Settings |
| **ИИ-модель** | Поддержка **OpenAI API** (`gpt-4o`, `gpt-4o-mini`), **Anthropic Claude** (`claude-3-5-sonnet`), **Gemini** и встроенный отказоустойчивый интеллектуальный Sommelier AI (работает без ключей из коробки) |
| **Источник каталога / База данных** | Локальная ольфакторная база на 90+ культовых нишевых и люксовых ароматов (Tom Ford, Kilian, Creed, MFK, Byredo, Le Labo, Amouage, Ganymede, Bois Impérial, BDK и др.) + адаптер для внешних API (Scento API) |
| **Шаг 1: Инициализация** | Поиск и валидация аромата по каталогу (с поддержкой русских названий, опечаток и сленга: *«лост черри»*, *«бакара 540»*, *«ганимед»*), извлечение пирамиды нот (верх, сердце, база), семейства и характера |
| **Шаг 2: Интервью** | Генерация **ровно 3 точечных вопросов** сомелье: 1) повод/уместность, 2) шлейф/стойкость, 3) ноты-антипатии |
| **Шаг 3: ТОП-10** | Формирование персонального рейтинга из 10 ароматов, ранжированных от точного попадания к смелым альтернативам |
| **Анти-галлюцинации** | **100% строгая валидация**: каждый элемент выдачи проходит проверку через валидатор базы данных. Выдуманные бренды или парфюмы отсекаются и замещаются проверенными формулами |
| **Формат JSON** | Строгое соответствие ТЗ (`status: "success"`, `recommendations: [...]` с полями `rank`, `brand`, `name`, `family`, `notes`, `reason`) |
| **Интерфейс** | Премиальный веб-интерфейс в эстетике Haute Parfumerie (темная гамма, золото, стекломорфизм, интерактивные карточки нот) |

## 3. Системный промпт сомелье

Внедрен в логику LLM-запросов (`app/services/prompt_manager.py`):

```text
Ты — элитный парфюмерный сомелье и эксперт по подбору ароматов с многолетним опытом. Твоя задача — помочь пользователю найти идеальный парфюм.

Алгоритм работы:
1. Пользователь называет свой прошлый любимый парфюм.
2. Проанализируй этот аромат: его семейство, характер, ключевые ноты (верх, сердце, база) и настроение.
3. Задай ровно 3 коротких, точных и живых вопроса, чтобы сузить круг поиска (куда носить, какой шлейф предпочтителен, есть ли ноты-антипатии). Веди диалог естественно.
4. После получения ответов выдай ТОП-10 рекомендованных ароматов.

Правила для выдачи ТОП-10:
- Только реальные, существующие на рынке ароматы. Никаких галлюцинаций!
- Для каждого аромата указать: Бренд, Название, Основное семейство, Ключевые ноты и короткое обоснование («Почему он тебе зайдет»).
- Ранжировать список от точного попадания к смелым альтернативам.
```

## 5. Быстрый старт

### 1. Клонирование и установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения (опционально)
Скопируйте пример:
```bash
cp .env.example .env
```
*Если ключи API не указаны, сервис автоматически работает на интеллектуальном встроенном движке Sommelier AI.*

### 3. Запуск сервиса
```bash
./run.sh
```
Или напрямую через uvicorn:
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8008 --reload
```

- **Веб-интерфейс**: [http://localhost:8008](http://localhost:8008)
- **Интерактивная Swagger документация**: [http://localhost:8008/docs](http://localhost:8008/docs)
- **ReDoc**: [http://localhost:8008/redoc](http://localhost:8008/redoc)
